# Pizza Sales SQL Analysis Project

## Objective
Analyze pizza sales data to identify revenue trends, customer behavior, and product performance.

## Tools Used
- PostgreSQL
- VS Code
- SQLTools

## SQL Concepts Used
- Joins
- Aggregations
- GROUP BY
- HAVING
- Window Functions
- Subqueries
- CTEs

## Key Business Insights
- Highest revenue-generating pizzas
- Most ordered pizza categories
- Peak ordering hours
- Revenue trends over time
